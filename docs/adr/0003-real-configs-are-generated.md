# Real-model config blocks are generated from published files

The 2026-09 audit parsed the published tokenizer.json files and found every hand-written tokenizer block in Chapter 4 wrong. Any block presented as a real model's configuration is now generated by a script in tools/ from the published file and labelled with its origin and version. Files from gated repos are committed as dated snapshots, since CI cannot fetch them. Hand-written blocks remain allowed, but must be labelled illustrative. Checking hand-written blocks against the files once was rejected, because the next edit reintroduces the drift; deleting real configs was rejected, because comparing real configs is some of the book's most useful content.
